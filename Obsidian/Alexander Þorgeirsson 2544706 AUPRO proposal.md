# Describe the theme or key idea behind your project
---
Simply to simulate the Yamaha DX7, an FM synth, using Super Collider. Most importantly, it will feature the composable oscillators and some, if not all, presets that came with the original DX7.
# Project research and AI collaboration strategy
---
There have been previous attempts to emulate the DX7, namely the FM plugin synth called "*dexed*".
[Dexed](https://asb2m10.github.io/dexed/) is a beast of a repository that tries to emulates the DX7 to a customizable degree of authenticity. It also has a [cartridge manager](https://asb2m10.github.io/dexed/#cartridge-manager) that can parse original .syx files that came with the preset cartridges. This repository will be pivotal in recreating some of the classic DX7 sounds.
